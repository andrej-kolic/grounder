# Security Policy

## Reporting a vulnerability

Report security vulnerabilities privately through GitHub's
[Security Advisories](https://github.com/andrej-kolic/grounder/security/advisories/new) —
not a public issue.

Include what's affected, how to reproduce it, and its impact. Expect an acknowledgment
within a few days, and coordination on a fix and disclosure timeline before anything is
made public.

## Supported versions

Only the latest published version is supported — `grounder` on npm, and the VS Code/Cursor
extension (Grounder Xplorer) on the VS Code Marketplace and Open VSX, each versioned
separately. Check the version installed against the current release on npm or the
Marketplace/Open VSX listing directly; `grounder doctor`/`migrate` check your local
configuration against your installed CLI, not against what's newest upstream.
